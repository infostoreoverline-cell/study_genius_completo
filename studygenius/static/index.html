        IL TUO TEAM DI MODELLI

        Modelli e chiavi API

        Le chiavi servono per chiamare i tuoi account. Non vengono incluse nei PDF, nei sorgenti scaricabili o nella repository.

        Se selezionato, vengono salvate in un file locale privato in chiaro, escluso da Git. Altrimenti restano in memoria fino alla chiusura. I campi lasciati vuoti conservano le chiavi della sessione.

        Le eventuali chiavi in un file .env vanno rimosse anche da quel file.
